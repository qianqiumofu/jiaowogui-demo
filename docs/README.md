# 开发文档索引

给接手同学的导航。业务口径唯一来源是根目录 `业务规则基线.md`，这里只写「怎么做」和「现在到哪了」。

## 接手第一步读什么

1. 根目录 `AGENTS.md`——硬约束，先看禁止操作。
2. 根目录 `业务规则基线.md`——规则 R01—R20 唯一来源。
3. [`18-检查进度与接手清单.md`](18-检查进度与接手清单.md)——**当前交接现场与剩余项，一站式状态。**
4. [`17-完整Demo交接.md`](17-完整Demo交接.md)——已实现能力的接口级说明。
5. 之后按任务查下面的操作手册。
