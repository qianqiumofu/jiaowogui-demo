# 最初设想与实际实现核对（2026-11-19）

> 历史核对快照。当前交接状态、已修复项与剩余项以 [`18-检查进度与接手清单.md`](18-检查进度与接手清单.md) 为准；接口级实现说明见 [`17-完整Demo交接.md`](17-完整Demo交接.md)。

本页替代 11 月 18 日的缺口快照。核对依据为业务基线、路由、领域服务、迁移、页面与真实 PostgreSQL 测试。身份、启动和验收记录见 [17-完整Demo交接.md](17-完整Demo交接.md)。

| 原缺口 | 当前实现与核对位置 |
| --- | --- |
| 多岗位与上级权限管理 | identity/school、authorization/management、roles；基础身份和职责分离，校级配置学院负责人，学院管理本院教师及学生，撤权使持久会话失效 |
| 学生主动查看住宿 | /me/profile、/me/residence 与我的身份页面，仅本人读取 |
| 专职思政与兼职辅导员 | IDEOLOGY 与 COUNSELOR 同业务权限，明确分配学生；普通 TEACHER 不自动取得名册权限 |
| 完整负责学生名册 | directory/students 与 StudentsView；学院、专业、年级、班级、姓名/学号筛选，后端范围收窄，包含未预约学生 |
| 核验与一次凭证、原子签码 | verification/service、access/service、0016；版本绑定，同事务消费签码，失败审计，SVG 编码异常整体回滚 |
| 学生二维码与本人正式记录 | VerificationPanel、MyRecordsView；SVG、服务端状态轮询、本人独立记录入口 |
| 设备失败/未知、回执及对账 | access/receipts；持久尝试、设备认证、事件幂等、冲突拒绝，UNKNOWN 不产生正式返宿，不恢复旧码 |
| 只追加证据与纠错 | returns/service、0017；唯一学生业务夜、QR/人工统一写入、证据和更正追加、原始记录保留 |
| 订阅与自动报告 | reports/subscriptions、worker/scheduler；日报周报独立开关，投递重查订阅及职责，目录真实展示标签 |
| 风险事件、跟进与规则版本 | risk/events、policy；正式返宿事实触发，状态跟进审计、周期评估和版本配置；园区主动查询而不接风险推送 |
| 代班指派 | directory 领域出口、duty/router、DutyView；园区指派/撤回，服务端生效范围，宿管不自授 |
| 长期调度与崩溃恢复 | 单 worker；滚动排快照、报告、风险与清理，租约重领、领取代次隔离、退避；延迟汇总读取零点预约修订 |
| 跨模块数据边界 | 统计/报告调用目录与返宿出口，返宿调用 access 读出口，access 调预约/核验/返宿服务；不互调 HTTP |

预约自动通过、无限改期、唯一正式返宿、园区聚合统计及受控导出等原有能力保留。R15 始终禁止超时未返宿提醒，当前没有新增此类任务或通知。

真实 PostgreSQL 最终回归 248 项通过（含 42 项完整 Demo 专项测试），前端构建与契约检查另见最新交接验收。没有把占位路径或返回空数组当作功能完成。迁移单头已到 0018（含子列宽度与 users.college_org_id 外键的结构一致性修复），详见 [18-检查进度与接手清单.md](18-检查进度与接手清单.md)。
