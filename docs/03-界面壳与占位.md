# 界面壳与占位约定

底座已经提供四角色可登录的完整外壳，业务页面是占位。她的开发方式是在占位面板上替换实现，不需要重画布局。

## 现在长什么样

| 入口 | 路由 | 内容状态 |
| --- | --- | --- |
| 登录页 | `/` | 已可用：读取 `GET /auth/demo-accounts` 列出四个合成账号 |
| 学生 · 晚归预约 | `/app/student/reservation` | 空列表（契约形状已定）+ 核验出码占位（M3） |
| 学生 · 我的返宿记录 | `/app/student/records` | 空列表 |
| 辅导员 · 负责学生 | `/app/counselor/students` | 待目录同步提示 |
| 辅导员 · 日报与周报 | `/app/counselor/reports` | 占位（M4） |
| 宿管 · 今晚名单 | `/app/dorm/tonight` | 已实现：当夜名单 + 改期/撤销异动 + 门禁通行「已通行 X / 共 N 人」；等 A 的 `reservation.list_for_building` 时显示 501 |
| 宿管 · 现场补录 | `/app/dorm/manual-entry` | 已实现：本楼栋名册检索 + 选人补录（带备注与幂等键），与扫码同一条唯一约束，重复提交不会多出一条返宿 |

| 门口终端（模拟） | `/terminal` | 已实现：选终端身份 + 粘贴令牌调 `POST /device/scan`，明确标注模拟、不会真实开锁 |
| 设置 · 操作指南 | `/app/settings`、`/app/guide` | 已可用：演示时钟推进、会话信息、全局使用说明 |

## 三种面板状态

`DataPanel.vue` 统一处理后端返回，不要各页面自己写一套错误样式：

| 后端返回 | 面板表现 |
| --- | --- |
| `200` + `items: []` | 「当前没有记录」占位，说明接口按契约返回空列表 |
| `200` + 有数据 | 渲染数据 |
| `501 NOT_IMPLEMENTED` | 「该能力尚未实现」并显示负责人与阶段 |
| `403 FORBIDDEN_ACTION` / `SCOPE_UNRESOLVED` | 「后端已拒绝此操作」并显示错误码 |
| 其他错误 | 显示 `code`、`message`、`request_id`，方便一起排查 |

## 文案规则

- 一个意思一句短话，正式语气，不写感叹号。
- 全局使用说明只放在「设置 → 操作指南」，页面里不重复解释同一件事。
- 二次确认使用非模态的展开面板，不要 `window.confirm`。
- 涉及模拟能力的地方必须写明「模拟」，例如模拟人脸核验、模拟门禁、模拟邮件预览。

## 布局与交互底线

- 学生按手机宽度设计（约 390px），宿管按平板宽度（约 1024px 横屏），园区与辅导员按桌面宽度。
- 次要筛选默认折叠，主操作保持单一焦点。
- 动效只用 240ms 左右的淡入与 4px 上移，并响应 `prefers-reduced-motion`。
- 新增页面在 `src/features/<role>/` 内，公共组件放 `src/shared/`；不要新建第二套布局壳。
