# 完整 Demo 与分层身份 Implementation Plan

**Goal:** 完成 docs/16 中 Demo 范围的缺失功能，并加入上级部门授权的多岗位身份。
**Architecture:** 基础身份由模拟学校统一认证给出，岗位与负责范围存数据库；单 FastAPI、单 PostgreSQL、单 Vue，跨模块用领域出口。原合并暂存状态保留，不改旧迁移。
**Tech Stack:** FastAPI / SQLAlchemy / PostgreSQL 17 / Vue 3，新增能力先契约后实现。
**Spec:** 用户 2026-11-18 补齐要求，业务规则基线 R01—R20，docs/16。

## Global Constraints
- 不建立超时或未确认返宿提醒任务；风险只给负责人员与当班宿管，园区不接风险推送。
- 预约自动通过、无限改期；时间全由服务端决定；演示数据全部合成。
- 所有数据库和并发验收使用隔离真实 PostgreSQL；迁移只追加单头。
- 学生／教师基础身份不能由工作角色授予接口伪造；管理员不能通过普通授予接口创建超级管理员。
