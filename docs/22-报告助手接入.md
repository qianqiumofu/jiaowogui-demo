# 报告助手：未配置模型时的使用与后续接入

## 当前可以使用什么

辅导员、专职思政、学院负责人登录唯一入口 `http://127.0.0.1:5174` 后，导航中可见“报告助手”。可以查看状态、编辑问题和查看建议；未接入模型时生成按钮禁用，不发起外部模型请求，原有晚归查询继续可用。

目前已完成可接入的受控工具循环及接口模拟测试，**尚未申请或接入真实“致远一号”模型，不能把页面存在当作真实模型已经可用**。学生预约助手、自动发送报告、聊天持久存储及任意日期/筛选的自然语言查询不在首版范围。

## 开通 API 后配置

先向学校申请获准模型，确认接口支持 Chat Completions 的 `tools` / `tool_calls`，并支持连续发送 `assistant.tool_calls` 与 `tool.tool_call_id`。兼容层不使用 OpenAI SDK，也不要求模型来自 OpenAI；协议参考 [官方工具调用说明](https://developers.openai.com/api/docs/guides/function-calling)。具体“致远一号”地址、模型名、鉴权和协议支持以学校发放说明为准，不预填猜测值。

在本机已忽略的 `apps/api/.env` 中配置以下四项，密钥不要贴到聊天、截图或代码中：

```dotenv
AGENT_PROVIDER=OPENAI_COMPATIBLE
AGENT_BASE_URL=https://学校发放的接口地址/v1
AGENT_MODEL=学校发放的模型名称
AGENT_API_KEY=只在本机填写
```

`AGENT_BASE_URL` 是包含版本前缀的基址，后端仅追加 `/chat/completions`，不要再次写完整端点。上面都是说明占位值，未取得学校参数前保持 `.env.example` 中的 `AGENT_PROVIDER=DISABLED`。地址或凭据不完整会继续显示不可用。

修改配置后需要重启对应 API；仅刷新网页不会重建后端配置缓存。按 `tmp/campus-experience-processes.json` 核对进程后停止本环境的 API/前端/worker，再运行 `scripts/start-campus-experience.ps1`，不要启动第二套端口或使用重置数据参数。密钥仅用于服务端，不返回前端状态接口。

启用状态只代表配置填写完整，不代表模型接口已通过连通性和兼容性验收。首次真实接入时用合成数据验证“本周总结”“本周对比上周”和继续追问；错误码会区分不可用、模型接口错误、未知工具、范围变化、超时与执行限额。接口地址/凭据/响应原文不写入错误信封。

## 处理流程与边界

1. 后端验证 `agent:use`。仅首版角色可用；园区和校级没有自动获得助手权限。
2. 模型只看到用户问题和最近 4 个用户问题；没有自动读取学生原因或个人资料的工具。对话仅存本页，刷新后清空。
3. 模型调用 `read_period_statistics(period, window)`，后端重新解析当前会话与范围，再通过统计领域服务读取六项聚合指标。外部模型得到日期与聚合数，不得到学生姓名、学号、联系方式或负责学生 ID。
4. 模型调用 `finish_report(source_ids, compare)`。来源必须是本次真实查询；后端生成所有数字和对比，不展示模型自行编造的数字或自由正文。工具不提供写预约、开锁、通知、任意 SQL 或任意 HTTP。
5. 报告显示引用编号、区间、执行依据和限制。未确认返宿不代表已经证明未归，不产生超时提醒、风险推送或处分。
6. 本次执行工具/来源与结果代码保存在既有审计日志；不记录问题原文、模型原文或密钥。范围或会话在生成过程中变化即停止，不返回旧范围结果。

当前工具支持 DAY/WEEK/MONTH，日期由请求开始时的服务端业务时钟确定：CURRENT 是前一已结束业务夜所在日/自然周/自然月至该夜；PREVIOUS 是前一日/上一完整自然周/月。周/月对比可能不等长，报告明确天数，不把原始差值视为同长增长率。每次取数按当时数据读取，不承诺多个工具执行之间数据库不会发生业务变化。

## 可调执行上限（Demo 默认）

| 配置 | 默认 | 含义 |
| --- | --- | --- |
| AGENT_TIMEOUT_SECONDS | 20 | 单次模型网络超时上限 |
| AGENT_TOTAL_SECONDS | 60 | 总流程时长预算 |
| AGENT_MAX_ROUNDS | 4 | 最多模型轮次 |
| AGENT_MAX_TOOL_CALLS | 6 | 总工具调用次数，含完成报告 |
| AGENT_MAX_RESPONSE_BYTES | 1048576 | 单次模型响应字节上限 |
| AGENT_MAX_OUTPUT_TOKENS | 1000 | 请求的模型输出 token 上限 |

请求契约最多 1000 字和 4 条前文问题，每条前文最多 1000 字。阈值属工程默认，不是学校规则。首版未实现正式模型配额、账号频控或生产并发压测，真实部署前需按学校配额核定。
