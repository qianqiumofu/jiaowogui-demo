# 模块职责与领域出口（2026-11-19）

一个应用、一套数据库、一个前端。模块负责人仍按根目录双人协作分工；本轮是用户授权的跨模块联合整合，后续改动继续遵守分工。模块之间调用领域函数，不互调 HTTP 或直接操作对方表。

| 模块 | 负责人 | 已实现 |
| --- | --- | --- |
| identity / authorization | A | 统一模拟登录、本地宿管例外、持久会话、多岗位、后端动作/范围、校级/学院授权及审计 |
| reservation | A | 唯一预约、自动通过、无限改期、版本、修订历史、撤码/正式返宿联动、零点历史读出口 |
| verification | A | 唯一窗口/码寿命计算、核验落库、一次凭证、同事务签码及 SVG |
| risk | A | 规则、弹窗、正式事实周期评估、事件去重、跟进、版本配置；园区不收推送 |
| reports / notification | A | 同源报告统计、订阅、周期任务、当前关系收件校验、模拟收件箱 |
| directory | B | 目录、住宿、负责关系、名册筛选、统计标签与值班领域出口 |
| access | B | 签码/撤码、设备认证、成功/失败/未知尝试、幂等回执与对账 |
| returns | B | 正式返宿唯一写入口、本人/范围查询、只追加证据与纠错 |
| building_list | B | 名单、零点修订快照、异动及正式通行展示 |
| statistics / exports | B | 同源分母、三值统计、聚合导出、本人资源隔离与保留期 |
| duty | B | 园区指派/撤回、生效区间、审计；宿管不自授跨栋范围 |
| worker | A 入口、双方处理器 | 滚动调度、业务键幂等、租约恢复、领取代次隔离、退避及清理 |

真实 SSO、目录同步、人脸供应商、门禁/NFC 与真实消息投递在校方授权后接入。当前结果全部合成，无外部模型仍可运行。最新验收见 docs/17-完整Demo交接.md。
