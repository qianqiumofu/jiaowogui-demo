## 分工

- **A**：学生端、辅导员端，以及身份、授权、预约、核验、风险、报告、通知、worker、根路由。
- **B**：宿管端、园区端，以及目录、代班、楼栋名单、通行与核销、返宿记录唯一写入、统计与导出。

一个仓库、一个后端应用、一套数据库；共享模块只有一个负责人。

## 当前状态

已可用：四角色模拟登录与会话轮换、后端动作权限与数据范围、统一错误信封与 `/api/v1` 契约、
演示时钟（含 `service_date` 与 `night_window`）、worker 单进程扫描、前端四角色界面壳与占位面板、
Docker Compose 与依赖锁定、前端接口类型由契约生成、**学生端当夜晚归预约全流程**
（一晚一条、自动通过、无限次改期、取消恢复、版本冲突 409、只追加修改历史，迁移 `0001_reservations`）。

尚未开始：通知模拟收件箱与后台任务表读写、核验与二维码核销、名单快照、日报周报、风险规则、统计导出，
以及 B 侧的目录/住宿/负责关系与种子数据。目录未落地时，辅导员、宿管、园区的越权范围会返回
422 `SCOPE_UNRESOLVED`。占位接口返回 501 `NOT_IMPLEMENTED` 或空列表，界面会显示负责人与阶段。

各模块的归属与「现在到底能调什么」见 [双人协作分工.md](双人协作分工.md) 的「当前交接状态」；
里程碑勾选项见 [详细路线图.md](详细路线图.md)。

## 三十秒跑起来

```bash
# 0) 先启动 Docker Desktop，等它就绪
cd "F:/A_homework/交我归"
docker compose up -d postgres

# 1) 后端
cd apps/api
./.venv/Scripts/python.exe -m uvicorn app.main:app --reload --port 8000

# 2) 前端（另开一个终端）
cd apps/web
npm run dev
```

打开 <http://localhost:5173>，点任意合成账号进入；后端接口文档在 <http://localhost:8000/docs>。
首次准备（装依赖、建虚拟环境、复制 `.env`）见 [docs/01-运行手册.md](docs/01-运行手册.md)。

## 边界

真实门禁、真实人脸识别、真实学校数据和真实消息投递都不属于 Demo。所有外部依赖通过适配器接入，
学校授权后替换为获准实现即可，不需要重写业务。模型服务关闭时全流程仍能运行。
