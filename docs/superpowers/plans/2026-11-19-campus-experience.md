# 千人合成校园与领导工作台 Implementation Plan

**Goal:** 生成可重复体验的 1000 名合成学生与完整管理关系，整理领导工作流。
**Architecture:** 保留原种子与固定验收样本，新增独立体验种子入口；业务预约、返宿分别调用所属领域服务。新增领导首页只导航已有获授功能，授权继续由服务端执行。
**Tech Stack:** FastAPI、SQLAlchemy、PostgreSQL、Vue 3；不新增依赖。
**Spec:** 用户本轮要求与业务规则基线 R02、R10—R21。

## 约束

- 全部合成；无超时提醒、园区不收风险推送；不改变职责授权范围。
- 不改表结构，无需迁移；不修改 B 模块服务，新增体验数据编排器消费领域函数。
- 原 66 人种子继续服务现有测试，千人场景使用新建的独立体验库，原开发库不重置。
