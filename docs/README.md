# 开发文档索引

给两位开发者的操作说明。业务口径唯一来源是根目录 `业务规则基线.md`，这里只写「怎么做」。

| 文件 | 内容 | 什么时候看 |
| --- | --- | --- |
| `01-运行手册.md` | 零环境安装路线、版本要求、首次准备、每天启动与自检命令 | 新机器第一次、每天开工 |
| `02-目录与所有权.md` | 目录结构、谁能改哪个文件 | 动手写第一个文件前 |
| `03-界面壳与占位.md` | 现有页面、面板状态约定、文案与布局底线 | 做界面前 |
| `04-做一个功能的标准流程.md` | 七步交付节奏，什么算「完成」 | 每做一个功能 |
| `05-Git提交与分支.md` | 提交格式、提交节奏、禁止操作、冲突处理 | 每次提交前 |
| `06-契约与接口同步.md` | 命名规范、改契约流程、SDK 生成方案 | 要加字段或新接口时 |
| `07-数据库与迁移.md` | 迁移规则、常用命令、硬约束 | 要建表或加列时 |
| `08-权限与数据范围.md` | 动作表、scope 判定顺序 | 写任何查询接口前 |
| `09-时间与边界.md` | 业务日、核验窗口、五分钟码、必测场景 | 写校验逻辑前 |
| `10-演示数据与账号.md` | 合成账号、固定 ID 约定 | 联调与写测试 |
| `11-检查清单.md` | 提交前逐项确认 | 提交前 |
| `12-常见错误与求助.md` | 报错含义、迁移多头、怎么提问 | 卡住时 |
| `13-待确认事项.md` | Demo 默认登记表与等学校的决定 | 想加新规则时 |
| `14-今晚名单交接.md` | 今晚名单：A 要提供的预约读接口、异动推送与 24:00 截止判定 | 联调名单与推送前 |

第一次按 `01 → 02 → 03 → 04 → 05` 顺序读，之后按任务查对应文件。
